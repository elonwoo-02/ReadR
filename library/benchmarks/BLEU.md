# BLEU

## Definition / Summary

Bilingual Evaluation Understudy (BLEU) is an algorithm for evaluating the quality of text generated by machine translation models. It measures n-gram overlap between generated text and reference translations, producing a score between 0 and 100 (higher is better).

## Related Research

- Tasks: Machine Translation
- Datasets: [[WMT 2014]]
- Related papers: [[Attention Is All You Need (NeurIPS 2017)]]
