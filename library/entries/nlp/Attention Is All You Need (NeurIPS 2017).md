# Attention Is All You Need (NeurIPS 2017)

> **In one sentence:** 提出 Transformer，一种完全基于多头自注意力的序列转换模型，替代 RNN 的递归计算，在 WMT 2014 上达到 SOTA 翻译质量（英德 BLEU 28.4、英法 BLEU 41.8），训练时间远低于之前模型。
