# WMT 2014

## Definition / Summary

Workshop on Statistical Machine Translation 2014 shared task datasets. Standard benchmarks for machine translation research. The Transformer was evaluated on two translation tasks: English-to-German (WMT 2014) and English-to-French (WMT 2014).

## Related Research

- Task: Machine Translation (English-German, English-French)
- Related papers: [[Attention Is All You Need (NeurIPS 2017)]]

## Evidence & Citations

- [x] English-German: 4.5 million sentence pairs, with 37k tokens shared BPE vocabulary (Vaswani et al., 2017, p.7)
- [x] English-French: 36M sentence pairs, with 32k token BPE vocabulary (Vaswani et al., 2017, p.7)

## Personal Notes

The Transformer achieved 28.4 BLEU on En-De (new SOTA at the time) and 41.8 BLEU on En-Fr (single-model SOTA).
